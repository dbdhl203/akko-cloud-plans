## 299 元到底买的是什么

这是多数测评一句话带过、但对决策最关键的地方。

**299 元年付款不等于月付款打折。** 年付 299 元是 512M 内存 / 10G 硬盘 / 500G 流量，月付 50 元是 768M 内存 / 10G 硬盘 / 600G 流量。月付按 12 个月算 600 元，年付 299 元差不多是它的一半，但换来的是少一档的内存和流量。很多文章把它简化成"折算 25 元/月"，听起来像是 768M 款的五折，实际不是。

**299 元年付比季付省 97 元。** 法兰克福和伦敦的 512M 款季付 99 元，四个季度 396 元，同配置年付 299 元，差额 97 元，约 24.5%。年付折算下来 24.9 元/月。如果你只是短期试水，季付多花的 97 元相当于买了三个月的退出权。

**512M 内存的实际边界。** 装完 Debian 或 Ubuntu 系统，剩三百多兆。跑 Nginx + PHP + MySQL 的小站勉强够，装个宝塔面板之后就比较紧张。要上 Docker、Node 服务或者 PostgreSQL，768M 起步更现实，月付 50 元那款比硬扛 299 元款划算。

## 线路实测：电信最好，联通次之，移动别抱太高期待

官方口径是三网回程 CN2 GIA，电信联通去程也走 CN2 GIA。第三方测评站对圣何塞机房做过一次路由跟踪，数据值得摆出来看。

测试环境是官方 looking glass，测试 IP 45.9.10.146，全国 ping 平均约 168ms，非高峰时段文件下载速度约 6MB/s。

**广州电信**：省级出口和国际出口都走 59.43 段，上海出境后直达圣何塞，末跳 145.9 / 146 / 146ms。这条路径和宣传一致。

**广州移动**：境内走 AS9808，到圣何塞的移动节点时延迟 169–205ms，之后转入 Cogent（AS174），经过三跳 Cogent 路由，末跳 235.1 / 280 / 322.2ms。也就是说移动去程并没有全程走优化线路，最后一段绕了第三方骨干，延迟被拉高到 235ms 以上，抖动也大。

**广州联通**：先走 AS4837 到上海，转 AS9929 出口，经 AS10099 从洛杉矶到圣何塞，末跳 172.9 / 335 / 400.7ms。路径本身是优质出口，但三次测试值跨度到 227ms，稳定性不如电信。

那位测评作者同时写明，looking glass 当时测不出回程，只测了去程。所以"三网回程 CN2 GIA"这条宣传在公开测试里并没有被完整验证过，能确认的是电信去程确实走 CN2 GIA。

结论按运营商分：

- 电信用户：这个价格能拿到 59.43 出口，延迟 146ms 左右，是三个运营商里体验最接近宣传的。
- 联通用户：能用，平均延迟在一百七八十毫秒，偶发高延迟，做建站没问题，实时交互类应用会有感知。
- 移动用户：去程绕 Cogent，延迟 235–322ms，晚高峰更明显。如果你主要用移动宽带，别指望"三网一样快"，最好先用官方 looking glass 自己 ping 一遍再决定。

法兰克福约 180ms（普通欧洲 VPS 通常 230ms 上下），伦敦约 200ms，伦敦实测下载 60Mbps、上传 20Mbps。这两个机房的价值在于欧洲落地，不是低延迟。

## 三个机房怎么选

按延迟排，圣何塞 168ms 最优，法兰克福 180ms 次之，伦敦 200ms 最后。三个机房同配置同价，所以选择基本只看你的用途。

**只有国内访问需求**：圣何塞。延迟最低，电信线路质量最好，流量和带宽也给得最大方。

**有欧洲业务或需要欧洲 IP**：法兰克福。比普通欧洲机房少 50ms 左右，做面向欧洲用户的小站、或者需要一个欧洲出口，比伦敦更划算。

**需要英国 IP 或特定地区落地**：伦敦。它排在最后不是因为差，是因为延迟最高，没有英国相关的需求就没必要为它多付 30ms。

## 限制和容易忽略的成本

**只收支付宝。** 没有微信、没有信用卡、没有 PayPal。对国内用户方便，对海外用户或者需要走公司报销流程的人就是障碍。

**客服不是 24 小时。** 工作时间中午 12 点到晚上 10 点，承诺工作时间内提交的工单 24 小时内答复、48 小时内解决，非工作时间由值班人员尽快答复。凌晨出故障只能等。这在同价位商家里算中规中矩，但别拿它跟有全天候值班的大厂比。

**换 IP 的政策变过，别照旧文章操作。** 有测评写到：刚开通 IP 被墙可提工单免费换，圣何塞每自然月免费换 1 次，超出 30 元/个，德国 15 元/个。但官方 Telegram 频道在 2026 年 6 月发过公告，说由于 IPv4 地址资源严重紧缺，已暂停受理除英国以外的 IP 更换请求。两份信息时间不同，以官方公告为准更稳妥。买之前先问客服当前政策，别默认一定能换。

**内存天花板低。** 三个机房的常规 CN2 套餐集中在 512M 到 1G，最高是 1G/20G 的 ¥699/年 款。跑两个容器、一个数据库再加个反代就到了。要 2 核以上的机器，这家没有对应产品。

**没有通用优惠码，促销也不叠加。** 特价套餐本身就是折后价，商家几乎不发码，偶尔在双十一、春节这类节点做活动，信息发在 Telegram 频道。想等降价的话，先确认自己要的机房有货：德国机房 2025 年 11 月补过一次货，圣何塞也出现过售罄再补的情况。

**退款条款资料里没有。** 我看到的测评和页面都没提退款政策，既不能说支持，也不能说不支持。下单前在工单里问清楚。

## 适合谁，不适合谁

**适合**：个人博客和小型展示站；需要一个国内访问速度还行的海外节点做跨境小业务；学 Linux、练手、跑点轻量脚本；预算卡在三百元一年、又不想用普通 163 骨干线路的人。

**不适合**：要跑 Windows 上的重型应用、数据库集群、多个容器编排的；需要 2 核以上 CPU 的；只能微信、信用卡或 PayPal 付款的；业务要求 7×24 小时技术支持响应的；需要书面 SLA 和赔付条款的。

还有一类人不需要买：如果你只是偶尔科学上网、看视频，市面上有更便宜的非 CN2 方案，CN2 GIA 的溢价你享受不到。

## 常见问题

**有优惠码吗？**
没有通用优惠码在流通。特价套餐已是折后价，不支持叠加。节日活动看官方 Telegram 频道。

**能解锁 Netflix 这些流媒体吗？**
部分套餐可以申请原生 IP，或者提供 DNS 解锁服务，测评里提到的平台包括 Netflix、Disney+、YouTube Premium、NBA TV。但"哪个机房有原生 IP"的说法在几篇资料里互相矛盾，有的说圣何塞，有的说德国。下单前直接问客服你要的那款能不能配，别按文章里的说法默认。

**IP 被墙了怎么办？**
先提工单问当前政策。2026 年 6 月官方公告已暂停英国以外的换 IP 请求，恢复时间未说明。这是买这家之前最该确认的一件事。

**能装 Windows 吗？**
KVM 虚拟化，可选 CentOS、Ubuntu、Debian、Windows Server，后台可以自助重装、重启、重置密码。512M 内存装 Windows 会非常吃力，至少 1G 款。

**续费会涨价吗？**
我看到的资料里没有首期价与续费价差异的说明。下单页的购物车会显示续费周期的价格，付款前自己扫一眼。这是所有 VPS 都该养成的习惯。

**稳定性怎么样？**
官方频道在 2026 年 9 月发过公告，英国 CN2 一台宿主机硬盘故障，已重建到其他宿主机，受影响实例延长 1 个月可用时长。2025 年 1 月也有过一次英国宿主机失联，约 60 名用户受影响。硬件故障在任何商家都会发生，值得看的是处理方式和补偿。有长期用户反馈日常使用比较平稳，偶尔收到维护通知，这类说法没有具体出处，只能当参考。
